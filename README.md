<h1 align="left">World Population Scraper</h1>

###

<p align="left">This Python script uses BS4 and  scrapes population data by country from the Worldometers website, processes the extracted HTML table content, cleans the data, and saves it into a CSV file for further analysis.</p>

###

<h2 align="left">Features</h2>

###

<p align="left">• Fetches HTML content from the target URL.<br>• Manages connection errors, request timeouts, and unexpected issues.<br>• Processes HTML table content, removes unwanted tags, and cleans extracted data.<br>• Saves processed population data into a CSV file.</p>

###

<h2 align="left">Requirements</h2>

###
```bash
pip install requests pandas beautifulsoup4 lxml
```
